Using .vimrc

A plain-language, section-by-section tour of my personal Vim configuration — what the file is, how to install it, and exactly what every line does.

Vim configuration ~60 settings Zero plugins github.com/ruffyleaf/myvimrc

01What is a .vimrc?

The .vimrc is Vim's startup script. Every time you open Vim, it looks for this file and runs each line as if you had typed the command yourself. It's how you turn a bare-bones editor into one that matches how you like to work — line numbers, sensible search, tabs that behave, keys that do what you expect.

It lives in your home directory, so Vim finds it automatically:

# Linux / macOS
~/.vimrc

# Windows (PowerShell)
$HOME\_vimrc

A few things worth knowing before we read the file:

Lines beginning with a double-quote " are comments. Blank lines are ignored. Later settings override earlier ones, so ordering matters when you repeat a set.

Editing live? After saving changes to your .vimrc, apply them to the current Vim session without restarting by running :source % (the % means "the file I'm editing right now").

02Installing this config

Grab the repo and drop the file into your home directory. Back up anything you already have first.

# Clone the repository
git clone https://github.com/ruffyleaf/myvimrc.git

# Move into it
cd myvimrc

# (Optional) preserve any existing config
[ -f ~/.vimrc ] && cp ~/.vimrc ~/.vimrc.bak

# Install: copy .vimrc into your home directory
cp .vimrc ~/.vimrc

Open Vim on any file and the settings are instantly active. Now let's walk through what you just installed.

03Appearance & movement

The opening block — and a "Better cursor movement" section later on — sets up how the editor looks and how the viewport follows you.

filetype plugin indent on
syntax on
set number
set relativenumber
set cursorline
set scrolloff=8
SettingWhat it does
filetype plugin indent onDetects the file type and turns on its bundled plugins and indentation rules — the foundation the per-language tweaks later rely on.
syntax onEnables syntax highlighting.
number + relativenumberShows absolute line numbers for the current line and relative counts above/below. Perfect for 5j/3k-style jumps while still knowing where you are.
cursorlineHighlights the line your cursor is on so it's easy to find.
scrolloff=8Keeps 8 lines of context above/below the cursor when scrolling, so you're never slammed against the window edge.

04Search that behaves

These four lines make searching fast, forgiving, and quiet.

set incsearch
set hlsearch
set ignorecase
set smartcase
  • incsearch — jump to the first match as you type, instead of waiting for Enter.
  • hlsearch — highlight every match in the file. (See the F4 shortcut below for toggling this off when it gets noisy.)
  • ignorecase — searches are case-insensitive by default.
  • smartcase — the clever counterpart: if your search term contains an uppercase letter, the search becomes case-sensitive automatically. Type /error to match everything, /Error to match only the capitalized form.

05Tabs & indentation

Consistent, spaces-based indentation with a clean delete/backspace experience.

set tabstop=4
set shiftwidth=4
set expandtab
set autoindent
set smartindent
SettingMeaning
tabstop=4A tab character is displayed 4 columns wide.
shiftwidth=4Auto-indent and the >>/<< commands shift by 4 columns.
expandtabPressing Tab inserts 4 real spaces instead of a tab character — the key to portable, consistent files.
autoindentNew lines copy the indentation of the previous line.
smartindentAdds a level automatically after lines ending in {, and helps in C-like languages.

06Brackets & auto-pairing

Vim shows you where brackets match, and typing an opening bracket inserts its partner for you.

set showmatch
set matchtime=2

inoremap ( ()<Esc>i
inoremap { {}<Esc>i
inoremap " ""<Esc>i
inoremap ' ''<Esc>i
inoremap [ []<Esc>i

nnoremap <C-j> {
nnoremap <C-k> }

showmatch briefly jumps the cursor to the matching bracket when you type ), }, or ]; matchtime=2 sets that pause to two-tenths of a second (the default is half a second, which many find too slow).

The inoremap lines are auto-pairing. Take inoremap ( ()<Esc>i: when you type ( in insert mode it inserts (), then <Esc> steps back one character and i re-enters insert mode — landing the cursor between the pair. You get a matched bracket with the cursor correctly placed. The same idea applies to {, quotes, and [.

Once the pair is written, Ctrl+j and Ctrl+k jump to the start { and end } of the current block respectively ({ and } are Vim's built-in "previous/next paragraph-or-block" motions).

07Mouse & split windows

Optional mouse convenience plus predictable window placement.

set mouse=a
set splitright
set splitbelow
  • mouse=a — enables the mouse in all modes: click to position the cursor, drag to select, scroll between splits.
  • splitright — a vertical split opens the new window to the right.
  • splitbelow — a horizontal split opens the new window below.

Together the split options make the layout follow the natural reading order: newest pane appears right / down.

08Persistent undo

Undo that survives closing the file — or the computer.

set undofile
set undolevels=1000

undofile writes your undo history to a hidden file (like .myfile.txt.un~) so u still works the next time you open the file. undolevels=1000 keeps up to 1,000 undo steps instead of the modest default of 100 — generous enough that you rarely lose a step you wanted.

09The status line

One cryptic-looking line that produces a very informative footer.

set statusline=%f\ %h%m%r%=%-14.(%l,%c%V%)\ %P

The backslashes are just spaces inside the option. Breaking it apart:

TokenDisplays
%fFile name (path as typed)
%h[help] flag when editing a help file
%m[+] modified flag when there are unsaved changes
%r[RO] read-only flag
%=Break point: everything left of it is pushed left, everything right is pushed right
%lCurrent line number
%cCurrent column
%VVirtual (screen) column — differs from %c when tabs are involved
%PPercentage through the file

The %-14.( … %) wrapper groups the (line,col) block with a minimum width of 14 and allows the middle to truncate gracefully on narrow windows. Net effect: path/to/file [+] (12,4) 57%.

10Keyboard shortcuts & grep

Function-key conveniences, plus a grep tweak.

nnoremap <F2> :w<CR>
nnoremap <F3> :q<CR>
nnoremap <F4> :set hlsearch!<CR>

set grepprg=grep\ -nH\ $*

F2 — Save

Writes the file (:w) from normal mode.

F3 — Quit

Closes the window (:q).

F4 — Toggle highlight

Flips search highlighting on/off with :set hlsearch! — great to silence stale highlights without changing your search.

Ctrl+j / k

Jump to the start or end of the current block, via the bracket motions above.

grepprg changes what Vim's :grep command runs under the hood. Setting it to grep -nH $* means results include the number (line) and Headers (file name), so :grep pattern *.py gives you clickable, file-aware matches you can step through with :cnext.

11Per-language tweaks

These autocmd FileType lines override the global tab settings for specific languages. They need filetype plugin indent on from section 03 to work.

autocmd FileType html       setlocal shiftwidth=2 tabstop=2 expandtab
autocmd FileType python     setlocal expandtab shiftwidth=4 softtabstop=4
autocmd FileType javascript setlocal expandtab shiftwidth=2 softtabstop=2
autocmd FileType css        setlocal expandtab shiftwidth=2 softtabstop=2
autocmd FileType json       setlocal expandtab shiftwidth=2 softtabstop=2

The convention encoded here: 4 spaces for Python, 2 spaces for HTML/CSS/JS/JSON. The setlocal keyword means "apply to this buffer only" so switching files won't leave the wrong indent width behind. softtabstop makes Tab and Backspace move in those same increments.

13Making it yours

This config is intentionally plugin-free, so it works on any machine with a stock Vim — no package manager, no downloads. To adapt it:

  • Prefer tabs, not spaces? Change set expandtab to set noexpandtab.
  • Different width? Edit tabstop/shiftwidth, and the per-language autocmd lines in section 11.
  • Numbers too busy? Drop set relativenumber and keep just set number.
  • A key feels wrong? Remap it with nnoremap <key> <action> in a new section at the bottom.

Test every change by saving and running :source % — if Vim shows an error, the line has a typo; fix and source again. Because everything is plain Vim script, nothing breaks across upgrades.
